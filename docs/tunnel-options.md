# 国内节点 / 永久域名：怎么选、怎么申请

> 价格与配额来自 2026 年的公开对比文章，服务商随时会改，**下单前以官网当期页面为准**。

## 一、先分清你要的是哪一件事

| 你要的 | 该走的路 | 地址会不会变 |
|---|---|---|
| 今晚就能用、地址临时 | 免费内网穿透（cpolar / natapp / 花生壳） | **会变**，重启就换 |
| 48h 实测期间地址固定 | 穿透**付费版保留二级域名** | 不变（但不是你的域名） |
| 长期用、要「永久域名」 | **自己买域名 + 一台服务器** | 永久，属于你 |
| 只解决「微信打不开」 | 国内穿透 + 二维码图片兜底 | 同上 |

**关键结论：内网穿透永远给不了真正的「永久域名」——域名不在你名下，服务商可以回收、限速、改政策。要永久就得自己买。**

## 二、四家免费/低价穿透对比

| 服务 | 免费额度 | 起步付费 | 实名 | 固定地址 |
|---|---|---|---|---|
| **cpolar** | 1 Mbps，流量不限 | 基础版 99 元/年（2 Mbps）、专业版 149 元/年（3 Mbps） | 要 | 付费版可保留二级域名 |
| **NATAPP** | 1 Mbps，**2 GB/月** | VIP-1 9 元/月（2 Mbps / 5 GB） | 要 | 付费版可绑自有域名（需备案）或买保留域名 |
| **花生壳（贝锐）** | 1 Mbps，有流量限制，2 条隧道 | 按年/按流量 | 要 | 付费版 |
| **神卓互联** | 1 Mbps，2 条隧道，宣称不限流量 | — | 要 | — |
| PassNAT | — | 6 元/月（20 Mbps / 50 GB） | 要 | — |

来源：[内网穿透价格对比（知乎）](https://zhuanlan.zhihu.com/p/2104283085906894933)、[NATAPP FAQ](https://natapp.cn/article/faq)、[贝锐花生壳免费版说明](https://hsk.oray.com/news/63421.html)

**留学生通知这个场景的流量很小**：一份通知的卡片页 + 几次 API，一个学生全套操作约 1–3 MB。20 个学生 + 几轮催办，**10 MB 量级**。所以免费额度的 1 Mbps 带宽和 2 GB 流量，做 48h 实测完全够——瓶颈从来不是流量，是**地址会变**和**微信能不能打开**。

## 三、cpolar 申请流程（我推荐先用这个）

1. 打开 <https://www.cpolar.com> 注册账号（邮箱即可）
2. **实名认证**：控制台里走支付宝/身份证认证，通常几分钟。**不做这一步拿不到隧道**
3. 下载 Windows 客户端并安装（或直接用命令行版）
4. 登录：控制台里复制 `authtoken`，然后
   ```powershell
   cpolar authtoken <你的token>
   ```
5. 起隧道（本地 3000 端口）：
   ```powershell
   cpolar http 3000
   ```
   终端会打印一个 `https://xxxx.cpolar.cn` 地址，**这就是公网入口**
6. 免费版每次重启地址会变；要固定就升级到基础版（99 元/年），在控制台「保留隧道」里绑定一个固定的二级域名

> 换成 cpolar 后**服务端代码一行都不用改**——它只是个 TCP/HTTP 转发。`.env` 里的 `PORT` 保持 3000 就行。

## 四、NATAPP 流程（基本一样）

1. <https://natapp.cn> 注册 → 实名认证（支付宝）
2. 控制台「购买隧道」选**免费隧道**（1 M / 2 GB 月）
3. 下载客户端 → `natapp -authtoken=<你的token>` → 打印 `http://xxxx.natappfree.cc`
4. 免费隧道地址每次都变；VIP-1（9 元/月）可以绑自定义域名

**备案的坑**：用它们给的**二级域名不用备案**（域名是他们的）。一旦你要绑**自己买的域名**，国内节点 Node 必须 ICP 备案，个人备案一般 1–3 周；**香港/海外节点不需要备案**（[NATAPP FAQ](https://natapp.cn/article/faq) 也这么说）。

## 五、要「真·永久域名」，正确做法是这个

```text
买的域名（约 30–60 元/年）
      ↓ A 记录
香港/新加坡轻量服务器（腾讯云/阿里云轻量，约 24–40 元/月，免备案）
      ↓
Caddy 自动 HTTPS（一行配置，证书自动续）
      ↓
node server/index.js（就是现在这个单体）
```

- 好处：地址永久、HTTPS 稳定、微信打开阻力最小、以后加功能不用搬
- 成本：**首年约 300–500 元**，之后每年 ~60 元域名 + 服务器月付
- 迁移改动：把 `lastmile/` 整个目录传上去，`npm install --production`，`npm run build`，用 `pm2` 或 Windows 计划任务守护。**数据库就是一个 `data/lastmile.db` 文件**，拷过去即可

要不要我把这套「上服务器 + Caddy + pm2」的脚本先写好？等你有域名和服务器，20 分钟能上线。

## 六、本项目用 cpolar 免费版的落地清单

按顺序做，10 分钟能通：

1. **注册 + 实名**：<https://www.cpolar.com> → 控制台 → 实名认证（支付宝，几分钟）
2. **装客户端**：官网下 Windows 版，装完在命令行能用 `cpolar` 就行
3. **登录**：控制台复制 authtoken，执行
   ```powershell
   cpolar authtoken <你的token>
   ```
4. **起隧道**（先确认本机 `npm start` 已经在 3000 端口跑着）
   ```powershell
   cpolar http 3000
   ```
   终端会打印 `https://xxxx.cpolar.cn`，这就是公网入口
5. **（建议）把地址写进配置**，让催办文案和二维码都用这个域名：
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\set-public-url.ps1 -Url https://xxxx.cpolar.cn
   ```
   这个脚本会改 `.env` 的 `PUBLIC_BASE_URL` 并自动重启服务。
   > 不填也能用——cpolar 会转发 Host 头，服务端一般能自己判断。填了更保险，尤其是你在反向代理后面时。
6. **验证**：浏览器打开 `https://xxxx.cpolar.cn/#/c`，用密码 `123456` 进去，发一份通知，把学生链接**用真手机 4G** 打开一次

**每次重启 cpolar 地址都会变**，变了就重跑第 5 步（一条命令），然后重新生成二维码发群。

**微信里必须真机测一次**：能用就直接用；被拦就退回二维码图片方案。

## 七、微信能不能打开

这一点**必须真机实测**，三条经验：

1. 国内穿透的二级域名，微信里**一般能打开**（很多人拿它做公众号回调调试）
2. 未备案域名偶尔出现「非官方网页」提示，但**不是拦截**，点继续就能进
3. 如果确实被拦死，兜底是**二维码图片**：把学生链接生成二维码，贴在一张通知卡片图上发群，学生扫码在浏览器打开。图片永远能发进群

所以无论用哪家，**先把「通知卡片图 + 二维码」这条路备好**，它不依赖任何域名政策。
